# FarrierOS Screen Map

## Global Navigation

Primary tabs:

- Today
- Calendar
- Clients and Barns
- Horses
- Prep Tomorrow
- Finish Job

On mobile, use a bottom navigation bar with large tap targets. On desktop, use a left rail or top bar with the same sections.

## Today

Purpose: start and manage field work.

Content:

- Today's date
- Route order
- Appointment cards
- Barn/property
- Horse list
- Status chips
- Start Job button
- Navigate button
- On My Way mock text button
- Mark Complete button

## Calendar

Purpose: see schedule pressure and recurring work.

Content:

- Day, week, month segmented control
- Scheduled appointments
- Due horses
- Overdue horses
- Simple reschedule action
- Recurring interval display

## Clients And Barns

Purpose: manage people, properties, access, and horse assignments.

Content:

- Client list
- Barn/property list
- Barn detail panel
- Horse assignments
- Gate code
- Parking notes
- Barn manager
- Access instructions
- Use Current Location button
- Manual address and map-pin fallback

## Horses

Purpose: find and work from the horse record.

Content:

- Search
- Horse cards
- Horse profile
- Owner
- Barn/property
- Temperament
- Safety notes
- Service interval
- Last service date
- Next due date
- Four large foot buttons: LF, RF, LH, RH
- Photo/document timeline
- Last verified setup
- Previous notes

## Foot History

Purpose: quickly review one foot before or during work.

Content:

- Foot name
- Latest verified setup
- Trimmed-foot photo placeholder
- Finished-shoe photo placeholder
- Shoe brand/model/size
- Clips, pads, wedges, borium
- Modifications
- Fit notes
- What changed this cycle
- History timeline

## Prep Tomorrow

Purpose: pre-shape shoes before arriving at barns.

Content:

- Tomorrow's route
- Horse cards grouped by barn
- Prior verified setup
- Four-foot summary
- Photo placeholders
- Fit comments
- Shoes Prepped toggle
- Prep note field

## Finish Job

Purpose: save an accurate service record quickly.

Content:

- Service type selector
- Current horse
- Setup fields
- Four-foot quick review
- Add photo placeholder
- Add voice-note placeholder
- Written notes
- Verified setup toggle
- Auto next-due date
- Save job button
- Owner summary mock preview

## Route Placeholder

Purpose: avoid paid maps APIs while supporting navigation intent.

Content:

- Destination barn
- Address
- Open maps search link
- Route order list

## Mock Communication Preview

Purpose: design for future SMS without sending real messages.

Content:

- Message recipient
- Message body
- Clear "Preview Only" label
- No send action in Prototype 0
