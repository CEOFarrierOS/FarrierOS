# FarrierOS User Flows

## Critical Prototype Flow

1. Open Today.
2. See Willow Creek Ranch and Fluffy in today's work list.
3. Tap Fluffy.
4. View Fluffy's horse profile.
5. Tap RF.
6. Review RF foot history, prior trimmed-foot photo placeholder, finished-shoe photo placeholder, fit notes, and verified setup details.
7. Open Prep Tomorrow.
8. Review tomorrow's route and prior verified setup.
9. Mark Fluffy as Shoes Prepped.
10. Open Finish Job.
11. Select service type.
12. Confirm or update shoe setup.
13. Add note or voice-note placeholder.
14. Mark current setup as Verified.
15. Save job.
16. See updated verified setup and next due date.

## Today Flow

1. Open Today.
2. Review route order and appointment cards.
3. Tap Navigate to open a maps search or route placeholder.
4. Tap On My Way to view a mock owner text preview.
5. Tap Start Job to enter the horse or appointment workflow.
6. Tap Mark Complete when work is done.

## Calendar Flow

1. Open Calendar.
2. Switch between day, week, and month.
3. Review due and overdue horses.
4. Open an appointment.
5. Reschedule using simple date controls.
6. Confirm recurring interval.

## Client And Barn Flow

1. Open Clients and Barns.
2. Choose a client or barn.
3. View assigned horses.
4. Review gate code, parking notes, barn manager, and access instructions.
5. Tap Use Current Location if browser permission is granted.
6. Use manual address or map-pin fallback when location is not granted.

## Horse Profile Flow

1. Open Horses.
2. Search or select a horse.
3. Review owner, barn, temperament, safety notes, interval, last service date, and next due date.
4. Tap LF, RF, LH, or RH.
5. Review foot-specific setup, photos, fit notes, changes, and previous notes.
6. Open the photo/document timeline.

## Prep Tomorrow Flow

1. Open Prep Tomorrow.
2. Review tomorrow's route in order.
3. For each horse, scan verified setup and visual placeholders.
4. Check shoe brand, model, size, clips, pads, wedges, borium, modifications, and fit notes.
5. Mark shoes prepped.
6. Leave any prep note needed for the next day.

## Finish Job Flow

1. Start from Today, Horse Profile, or an appointment.
2. Select trim, fronts, hinds, full set, or therapeutic.
3. Review current setup prefilled from verified setup.
4. Adjust foot setup if needed.
5. Add trimmed-foot or finished-shoe photo placeholders.
6. Add written note or voice-note placeholder.
7. Add What Changed This Cycle note.
8. Mark setup Verified if the setup is trustworthy for future prep.
9. Save job.
10. App auto-calculates next due date from the horse's service interval.
11. Owner summary preview is available but not sent.
